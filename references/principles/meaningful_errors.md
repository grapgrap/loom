# Meaningful Errors

실패 정보는 도메인의 공개 계약이다. 실패 종류, 원인과 발생 맥락을 보존하여 호출자가 계약에 맞는 대응을 선택할 수 있게 한다.

## 적용

- 입력 거절, 찾을 수 없음, 일시적인 외부 실패처럼 대응이 다른 실패를 구분한다. 실패한 작업과 대상, 문제가 된 조건을 남긴다.
- 외부 실패를 변환하면 자기 도메인의 어휘로 표현하면서 원인과 의미를 보존한다. 알 수 있는 경우 재시도나 수정에 필요한 조건을 전달한다.
- 계약에서 예상하는 실패와 구현의 결함을 구분한다. 예상하지 못한 결함을 빈 결과나 정상적인 업무 실패로 숨기지 않는다.

## 예시

재고 부족과 재고 조회 실패를 같은 빈 결과로 반환하면 주문 흐름이 거절과 재시도 중 무엇을 해야 할지 판단할 수 없다. 두 실패를 계약에서 구분하고, 외부 조회 실패의 원인과 맥락을 진단할 수 있게 보존한다.

## 경계

실패를 전달할 때 외부 구현의 내부 자료 전체를 공개 계약에 넣지는 않는다. 호출자가 대응할 정보와 원인 추적에 필요한 정보를 구분하여 보존한다.
