# View Boundary

화면은 표시와 입력의 책임을 소유한다. 외부 형식의 해석과 도메인 규칙은 별도의 책임으로 두어 화면을 실행하지 않고도 판단할 수 있게 한다.

## 적용

- 화면에는 입력 중인 값, 포커스, 펼침 상태와 표시 형식처럼 화면 자체에 속한 상태와 동작을 둔다.
- 외부 통신과 응답 변환은 인터페이스 경계에 둔다. 요청 흐름은 로딩과 실패에 대응할 책임이 있는 지점에서 조율한다.
- 도메인 규칙의 실행은 화면에서 요청할 수 있지만 규칙의 판단은 도메인이 맡는다. 표시를 맡은 하위 화면은 확보한 모델을 사용한다.

## 예시

주문 취소 화면은 취소 의사를 입력받고 결과를 표시한다. 취소 가능 여부는 주문 도메인이 판단하고, 결제사 응답의 변환은 외부 경계가 맡는다. 화면의 펼침 상태와 주문의 취소 상태를 같은 책임으로 취급하지 않는다.

## 경계

사용자 화면이 없는 프로그램에는 적용하지 않는다. 도메인이 없는 공통 표시·입력 단위에는 필요한 값만 전달한다. 별도의 책임이나 변경 이유 없이 단순한 표시를 여러 전달 계층으로 나누지 않는다.
