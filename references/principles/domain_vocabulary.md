# Domain Vocabulary

모델과 동작의 이름은 도메인의 개념과 역할을 일관되게 드러낸다. 코드의 어휘에서 어느 책임과 계약을 다루는지 읽을 수 있어야 한다.

## 적용

- 모델, 상태, 공개 동작을 정의하면 도메인의 전문가나 사용자가 쓰는 어휘를 확인하고 같은 개념에 같은 이름을 사용한다.
- 도메인의 의미를 일반적인 처리·관리라는 표현으로 대체하지 않는다. 동작의 목적과 모델의 역할이 이름에 드러나게 한다.
- 다른 도메인의 어휘는 인터페이스 경계에서 자기 도메인의 어휘로 변환한다. 서로 다른 개념을 이름이 비슷하다는 이유로 같은 모델로 취급하지 않는다.

## 예시

외부 결제사의 승인 응답을 결제 도메인의 승인 결과로 변환한다. 주문 도메인은 필요한 결제 상태를 자기 계약으로 받아 사용한다. 결제사의 상태 코드나 일반적인 데이터 처리라는 이름이 주문 규칙 전체에 퍼지지 않게 한다.

## 경계

도메인이 실제로 사용하는 기술 용어도 어휘가 될 수 있다. 외부와 내부가 같은 의미를 공유한다면 불필요한 번역을 만들지 않는다. 용어가 다르면 이름의 통일보다 의미의 차이를 경계에서 명시하는 것이 먼저다.
