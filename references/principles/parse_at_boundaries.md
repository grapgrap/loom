# Parse at Boundaries

외부 형식과 다른 도메인의 값은 경계에서 자기 도메인의 모델로 변환하고 검증한다. 경계를 통과한 값에는 내부에서 신뢰할 계약이 있어야 한다.

## 적용

- 외부 응답, 저장된 데이터와 입력을 받으면 형식의 해석, 검증과 모델 변환을 경계에 모은다.
- 타입을 사용하는 환경에서는 검증 결과와 내부 타입이 같은 계약을 표현하게 한다. 선언이나 강제 변환으로 확인하지 않은 계약을 주장하지 않는다.
- 검증한 형식은 내부에서 신뢰한다. 같은 형식을 확인하는 가드를 여러 내부 함수에 반복하지 않는다.
- 형식 검증과 현재 상태에 따른 업무 조건을 구분한다. 새로운 신뢰 경계를 통과하거나 외부에서 값을 변경할 수 있으면 그 경계의 계약을 다시 확인한다.

## 예시

저장된 주문 데이터를 읽을 때 주문 상태와 필수 값을 확인하여 주문 모델을 만든다. 주문 동작마다 같은 필드의 존재를 다시 검사하지 않는다. 다만 유효한 주문 모델이라도 현재 재고가 부족하면 주문을 거절할 수 있다.

## 경계

도구가 표현하지 못하는 외부 보장을 이용해야 한다면 그 근거를 확인하고 변환을 작은 경계에 한정한다. 도메인 규칙의 상태 판단을 형식 검증이라는 이유로 제거하지 않는다.
