# Verify Domain Contracts

책임, 모델이나 공개 계약을 바꾼 뒤에는 도메인의 불변 조건, 공개 동작과 의존 관계가 보존되는지 확인한다. 검증의 기대값은 요구사항과 계약에서 도출하고 현재 산출물에서 관찰한 증거로 판단한다.

## 적용

- 모델과 상태 변경은 허용하는 상태, 필요한 값과 잘못된 전이를 실제 입력과 동작으로 확인한다.
- 공개 계약은 호출자가 사용하는 경로에서 결과, 실패, 호출 조건과 변경 후에도 유지할 동작을 확인한다.
- 책임과 의존 관계를 옮기면 외부에서 내부 구현을 직접 참조하는 경로, 소비자를 향하는 역방향 참조와 구 계약의 잔존을 확인한다.
- 기대값을 만드는 데 구현의 논리를 다시 사용하지 않는다. 실행하지 못한 조건은 미확인으로 남긴다.

## 예시

주문 취소 규칙을 화면에서 주문 도메인으로 옮기면 화면 없이도 취소 가능 상태와 거절 상태를 확인한다. 공개 취소 경로에서 재고와 결제의 상태가 계약대로 변하는지도 검사한다. 함수가 호출됐다는 사실만으로 취소가 완료됐다고 판단하지 않는다.

## 경계

순수한 도메인 규칙은 독립적인 검사로 확인할 수 있다. 조합과 외부 구현에 관한 계약은 그 경로를 실행하여 확인한다. 구조 자체가 보존할 조건이면 참조 관계를 검사하되, 무관한 내부 구현의 형태를 동작의 기대값으로 고정하지 않는다.
