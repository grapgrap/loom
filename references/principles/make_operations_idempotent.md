# Make Operations Idempotent

재시도되는 상태 변경은 같은 요청의 반복이나 중단 후 재실행이 의도한 최종 상태로 수렴하게 한다. 도메인은 반복 실행에서도 자기 모델의 일관성을 보장한다.

## 적용

- 반복될 수 있는 상태 변경은 같은 요청을 두 번 실행했을 때의 결과를 확인한다.
- 초기화나 정리는 현재 상태와 목표 상태의 차이를 반영한다. 중단 후 다시 실행할 수 있으면 중간 상태와 완료 상태를 구분한다.
- 같은 요청의 재시도와 새로운 요청을 구분하고, 중복 실행에 대한 계약을 명시한다.

## 예시

같은 결제 승인 요청을 재시도했을 때 새로운 결제가 발생하지 않도록 요청의 식별과 승인 상태를 관리한다. 응답을 받기 전에 연결이 끊겼더라도 도메인이 이전 승인 여부를 확인하여 같은 결과를 반환할 수 있어야 한다.

## 경계

새로운 요청마다 결과가 누적되는 로그나 카운터의 의미는 보존한다. 누적되는 동작도 같은 요청의 재시도에 중복을 허용할지는 별도로 정한다. 한 번의 트랜잭션이 원자적이라는 사실만으로 요청의 중복 실행까지 막는다고 가정하지 않는다.
