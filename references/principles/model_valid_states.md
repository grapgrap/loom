# Model Valid States

도메인 모델은 허용하는 상태와 그 상태에서 유효한 데이터를 함께 표현한다. 상태의 일관성을 모델과 동작의 계약에서 보장하고, 호출자의 암묵적인 약속에 맡기지 않는다.

## 적용

- 모델을 정의하면 허용하는 상태와 각 상태에서 필요한 값을 정한다. 서로 양립할 수 없는 값의 조합을 만들지 않게 한다.
- 상태에 따라 필요한 데이터가 다르면 상태별 구조를 구분한다. 언어와 도구가 지원하면 필수 값과 분기의 누락도 검사하게 한다.
- 상태를 변경하는 동작은 허용할 전이와 보존할 불변 조건을 확인한다. 표현만 유효하다는 이유로 모든 전이가 유효하다고 판단하지 않는다.

## 예시

| 결제 상태 | 필요한 데이터 |
| --- | --- |
| 대기 | 결제할 금액 |
| 승인 | 승인 식별자와 승인 금액 |
| 실패 | 실패 종류와 원인 |

승인 정보와 실패 원인을 모두 선택적인 값으로 두면 승인 정보가 없는 승인 상태를 만들 수 있다. 상태별 필수 값을 보장하고, 환불은 승인된 결제에서만 수행할 수 있는 동작으로 정의한다.

## 경계

같은 데이터와 동작을 가진 값을 불필요하게 여러 상태로 나누지 않는다. 재고나 시간처럼 실행 시점에 변하는 조건은 도메인 동작에서 확인한다. 모델의 형태만으로 모든 업무 조건을 보장할 수 있다고 가정하지 않는다.
