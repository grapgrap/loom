# Dependency Direction

의존은 책임의 방향을 따른다. 조율과 표현은 하위의 계약과 모델을 사용하고, 모델과 자식 도메인은 자신을 사용하는 상위 책임을 모른다.

## 적용

- 모듈을 참조하면 그 참조가 어느 도메인과 역할을 향하는지 확인한다. 모델이 동작, 화면이나 실행 환경을 알도록 만들지 않는다.
- 부모는 자식의 공개 모델을 합성하거나 인터페이스를 사용한다. 자식은 부모의 개념과 호출 맥락을 참조하지 않는다.
- 도메인 동작에 외부 기능이 필요하면 도메인의 어휘로 계약을 정의한다. 구체적인 외부 구현은 그 계약을 따르고 조합 지점에서 연결한다.

## 예시

결제 동작은 결제 모델과 승인 계약을 사용한다. 특정 결제사의 응답 형식은 계약을 구현하는 외부 경계에서 해석한다. 실행 지점이 구현을 선택하여 연결하므로 결제 모델과 규칙을 바꾸지 않고 외부 구현을 교체할 수 있다.

## 경계

의존 방향은 호출의 시간 순서와 구분한다. 부모 모델이 자식의 공개 모델을 합성하는 것도 모델이 소비자에게 의존하는 관계와 구분한다. 순환 참조가 없더라도 하위 책임이 소비자의 사정에 묶여 있는지 확인한다.
