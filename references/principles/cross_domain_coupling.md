# Cross-Domain Coupling

도메인 간 결합은 같은 역할의 공개 모델과 인터페이스에서 이루어진다. 여러 도메인의 동작이나 화면을 연결하는 책임은 공통 부모나 조합 지점에 둔다.

## 적용

- 모델을 결합하면 부모가 자식의 공개 모델을 합성한다. 다른 도메인의 내부 상태를 직접 변경하지 않는다.
- 인터페이스를 사용하면 외부 도메인의 어휘와 형식을 자기 도메인의 모델로 변환한다.
- 여러 도메인의 동작을 잇는 흐름은 조율 책임을 소유하는 지점에 둔다. 형제 도메인의 내부 구현을 직접 호출하지 않는다.
- 여러 도메인을 보여주는 화면은 각 도메인의 표현을 상위에서 합성한다. 한 도메인의 화면에 다른 도메인의 내부 규칙을 넣지 않는다.

## 예시

주문 생성과 포인트 차감을 연결하는 구매 흐름은 두 공개 계약을 조율한다. 주문의 내부 동작이 포인트 차감의 내부 구현을 가져오지 않는다. 고객과 주문을 함께 보여주는 페이지도 각 도메인의 화면을 연결하며, 고객 화면이 주문의 내부 규칙을 소유하지 않는다.

## 경계

같은 도메인의 동작이 자기 모델에 의존하는 관계는 [Dependency Direction](dependency_direction.md)을 따른다. 두 도메인을 연결한다는 이유만으로 의미 없는 부모 모듈을 만들지 않는다. 조율의 고유한 책임은 [Earn Your Boundary](earn_your_boundary.md)로 확인한다.
