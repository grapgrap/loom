# 상태의 소유자와 변경을 명시한다

- 상태 변경은 그 상태를 소유하는 단위의 계약에 포함하고 이름과 호출에서 드러낸다. 조회 계약에 없는 상태 변경을 숨기지 않는다.
- 상태의 보관 위치와 규칙의 소유자를 구분한다. 변경의 허용 조건과 연관 값의 일관성은 그 규칙을 맡은 단위의 동작으로 보장한다. 호출자가 상태를 읽어 규칙을 판단하고 필드를 각각 바꿔야 한다면 [공개 계약](../principles/public_interface.md)이 필요한 책임을 소유하는지 확인한다.
- 암묵적인 전역 상태보다 명시적인 의존성을 사용한다. 공유 가변 상태의 범위와 수명을 줄이고, 필요한 상태는 소유자와 변경 책임을 밝힌다.
- 원본에서 계산할 수 있는 값은 기본적으로 별도 상태로 저장하지 않는다. 저장이 필요하면 원본과의 일관성을 유지할 책임을 한 곳에 둔다.
- 숨겨진 실행 순서를 전제하지 않는다. 필요한 순서와 동기화, 경합·재시도에서 지킬 불변 조건을 계약에 포함한다.
