# 변경 결과를 확인한다

- 요청한 동작과 보존할 계약이 유지되고, 관련 테스트가 통과했는지 확인한다. 실행할 수 없었던 검증과 테스트 우선 작업의 실제 제약은 구분해 알린다.
- 이름·흐름·공개 계약에서 판단과 상태 변경의 담당자를 알 수 있는지 확인한다.
- 새로 추가한 검증은 [입력 계약과 실행 조건](validation_and_preconditions.md)에 따라 유입 경로와 담당 책임을 확인한다. 생성 과정이나 내부 계약이 보장한 형식·값의 조건을 소비자에서 반복 검사하면 제거한다.
- 변경한 영역에 같은 책임의 명백한 중복, 고유한 책임이 없는 간접 참조와 사용하지 않는 코드가 남았는지 확인한다.
