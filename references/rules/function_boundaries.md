# 함수의 책임과 경계를 정한다

- 같은 책임을 수행하는 단계는 함께 두고, 독립된 정책이나 계약의 구현은 분리한다. 함수 길이·단계 수·매개변수 수만으로 분리하지 않는다.
- 매개변수는 해당 책임에 필요한 값과 의존성으로 한정한다. 관련 값이 고유한 계약이나 불변 조건을 가질 때 값 객체나 도메인 객체로 묶는다. 개수를 줄이기 위한 묶음은 만들지 않는다.
- Boolean 매개변수가 서로 다른 책임이나 계약의 동작을 선택한다면 별도 함수로 드러낸다. 예를 들어 공개·비공개 프로필의 계약이 다르면 `render_public_profile`과 `render_private_profile`로 나눈다.
- 같은 책임 안의 헬퍼는 [Consistent Expression](../principles/consistent_expression.md)에 따라 전체 흐름을 같은 방식으로 읽게 만드는 데 필요할 때만 분리한다. 어느 분기·단계·관련 함수의 표현을 일관되게 만드는지 확인한다. 각 조각에 이름을 붙일 수 있거나 한 가지 일을 한다고 설명할 수 있다는 이유만으로 분리하지 않는다.
- 조율하는 흐름의 의도와 순서가 일관되게 읽히도록 함수 분리와 인라인 표현을 함께 검토한다. 이미 한곳에서 자연스럽게 읽히는 단계를 흩뜨리거나, 세부 절차를 모두 감추기 위해 단계마다 헬퍼를 만들지 않는다.
- 도메인 판단과 I/O·프레임워크 연결·직렬화처럼 변경 이유가 다른 책임을 분리한다. 고유한 책임이나 계약이 없는 전달 계층은 만들지 않는다.
