# Write

## 누구에게 무엇을 전하는가

독자가 무엇을 알고 있고 이 글로 무엇을 판단하거나 해야 하는지 파악한다. 독자와 목적이 분명하면 바로 쓴다. 독립적으로 읽을 글에는 처음 보는 사람이 이해하는 데 필요한 배경을 넣는다. 교정과 요약에서는 원문의 뜻과 요청 범위를 보존한다.

주어진 사실만으로 쓸 수 있으면 그 범위에서 완성한다. 빠진 정보가 결론을 바꾸면 `$loom:work`에서 해당 근거를 먼저 확인한다. 사용자 결정, 저자의 제안, 실행으로 확인한 사실을 문장 안에서 구별한다. 예를 들어 당일 재접속 기록을 요약할 때는 당일 관찰로 적고, 다음 날의 동작은 그 조건을 확인한 근거가 있을 때 쓴다.

## 읽는 사람이 확인할 수 있게 쓴다

작성과 교정에는 [명확한 표현](references/clarity.md)을 적용한다. 문제와 판단 근거를 구성할 때는 [문서 프레이밍](references/framing.md)도 함께 적용한다. 원문에 있는 조건, 책임 주체와 제약을 남긴다. 여러 작업을 종합하면 중요한 판단에서 원본 대화나 산출물, 실행 기록을 찾아갈 수 있게 연결한다.

완성된 글을 요청했으면 독자에게 건넬 본문을 반환한다. 검토를 요청했으면 원문을 유지하고 영향이 있는 부분과 고칠 방향을 전한다. 작업 결과는 한 페이지 안에서 결론과 판단 근거, 사용에 영향을 주는 미확인 사항을 설명한다. 다른 스킬을 도울 때도 원래의 완료 판단과 사용자 확인 여부를 보존한다. 외부로 전달하는 일은 사용자가 맡긴 범위에서 수행한다.
