# Review

## 반례 확인

사용자가 검토를 맡긴 범위에서 합의한 계약과 완료 조건을 먼저 확인한다. 조건마다 산출물이 기대 결과를 어디에서 보장하는지 찾는다. 변경 설명에서 언급하지 않은 요구도 설계나 구현을 따라가며 충족 여부를 확인한다.

보장을 깨뜨릴 입력이나 사건 순서를 골라 계약 또는 실제 실행 경로를 따라간다. 테스트가 모의 객체로 대체한 경로와 실제로 실행한 경로를 구분한다. 지적을 보고하기 전에 그 조건을 이미 처리하는 경로가 있는지 확인한다.

## 검토 결과

검토만 맡으면 지적을 영향이 큰 순서로 전달하고 마친다. 지적마다 위치, 발생 조건, 기대 결과와 실제 영향, 근거를 제시한다. 확인한 결함과 추가 관찰이 필요한 의문을 구분한다. 반례를 찾지 못하면 확인한 범위를 밝힌다.
