# 지속 작업 세션에서 수행한다

독립적인 대화와 작업 맥락을 유지하며 작업을 위임받았을 때 읽는다. [공통 작업 기록](../../../references/task-record.md)에서 작업 ID, 조정 책임자, 현재 계약과 선행 결과, 작업 환경과 보고 경로를 확인한다. 원본 근거를 읽고 이해한 목표와 범위, 보존할 계약과 완료 조건을 대조한다. 모순이 없고 필요한 입력이 갖춰졌으면 전달받은 권한 안에서 진행하고, 착수에 영향을 주는 쟁점만 조정 책임자와 해결한다.

## 맡은 범위를 설계하고 수행한다

[work](../SKILL.md)와 필요한 전문 스킬로 맡은 결과를 완수한다. 조사, 설계나 검증만 맡았다면 그 범위를 지킨다. 독립적인 세부 설계에서도 공통 경계와 확정된 계약, 검토할 가정을 구분한다.

수행 중 새로 발견한 하위 책임이나 같은 수준의 별도 책임은 목표와의 관계, 경계와 의존 조건을 붙여 조정 책임자에게 전달한다. 다른 작업의 계약이나 범위에 영향을 주는 변경은 함께 조정한다. 맡은 범위에서 하위 작업 세션까지 조율할 권한이 있으면 [coordinate](../../coordinate/SKILL.md)를 적용하고, 그 범위의 메인 역할과 보고 책임을 명시한다.

내부의 부분 업무에는 허용된 위임 범위와 모델 정책에 따라 [orchestrate](../../orchestrate/SKILL.md)를 사용한다. 서브 에이전트가 반환한 결과를 검토하고 지속 작업의 산출물에 반영할 책임은 이 세션에 남는다.

## 사용자와 직접 소통하고 변경을 공유한다

사용자가 이 세션에서 질문하거나 보완을 요청하면 현재 작업과 연결해 답하고 수행한다. 범위, 공통 계약이나 우선순위가 바뀌는 결정은 조정 책임자에게 근거와 영향을 전달해 공통 기록과 관련 작업에 반영되게 한다. 이미 정한 권한을 다시 묻지 않고, 사람의 선택이 필요한 미결정 사항만 확인한다.

질문, 막힘, 공통 계약 변경과 검토 가능한 결과를 약속한 보고 경로로 전달한다. 원본 대화와 산출물, 조건별 검증 근거를 작업 기록에서 찾아갈 수 있게 한다.

## 제출 후에도 맥락을 유지한다

산출물과 검증 근거를 제출하고, 조정 책임자가 현재 계약으로 결과를 수락하게 한다. 보완 요청은 같은 작업 ID와 현재 계약으로 이어간다. 결과 제출 뒤 실행을 쉬더라도 대화와 작업 맥락을 유지하고, 후속 요청에서 계약과 산출물의 변화를 확인해 재개한다.

CI 실패 수정과 리뷰 반영은 맡긴 전달 지점과 실제 호스트 실행 수단의 범위에서 수행한다. 맡기지 않은 후속 작업을 계속 감시하거나 실행한다고 가정하지 않는다. 최종 전달과 정리는 조정 책임자와 정한 조건에 따르고, 남은 담당과 재개 근거를 공통 기록에 연결한다.
