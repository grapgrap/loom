# 위임받은 업무를 수행한다

전달받은 업무 ID로 [업무 CLI](context-work.md)의 `work show`를 읽고 목표, 범위, 완료 조건, assignment, 선행 결과와 작업 경로를 대조한다. 조율자가 지정한 worker ID를 actor로 사용한다. 전체 계획과 업무 간 조정은 메인 에이전트인 조율자가 맡고, 위임받은 에이전트는 맡은 범위의 세부 계획, 수행과 검증을 맡는다. 같은 워크트리의 다른 변경을 보존한다. 업무 간 충돌, 범위나 완료 조건 변경 또는 추가 위임이 필요하면 근거를 기록하고 조율자에게 요청한다.

수행 과정의 판단과 출처는 record에, 조건별 관찰, 근거와 남은 행동은 work report에 남긴다. 지정된 중간 결과와 막힘, 전제 변경도 조율자에게 보고한다. 공유 기록의 정리 담당자가 지정됐다면 [작업 맥락의 정리 규약](context.md#정리-시점을-판단한다)을 따른다.

수행을 마치면 work submit으로 결과를 고정하고 submission.ref, 실제 검증 조건과 결과, 변경 경로와 기록 ref를 지정된 반환 경로로 보고한다. 직접 complete하거나 자신의 결과를 수락하지 않는다. 보완 요청은 현재 명세와 지적 조건을 읽고 report와 submit으로 다시 제출한다.
