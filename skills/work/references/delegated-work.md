# 위임받은 작업을 수행한다

조율자가 전달한 목표, 범위, 완료 조건, 선행 결과와 작업 경로를 확인한다. 관련 합의와 원본 근거를 읽고 이해한 목표, 현재와 변경 후 동작, 보존할 계약과 검증 방법을 짧게 설명한다. 누락이나 모순이 있으면 조율자에게 알리되, 명세가 충분하면 별도의 이해 확인 승인을 기다리지 않고 착수한다.

전체 계획과 작업 간 조정은 조율자가 맡고, 작업자는 맡은 범위의 세부 계획, 수행과 검증을 맡는다. 같은 워크트리의 다른 변경을 보존한다. 작업 간 충돌, 범위나 완료 조건 변경 또는 추가 위임이 필요하면 근거와 함께 조율자에게 요청한다.

지정된 호스트 메시지와 결과 반환 경로로 보고한다. 수행 중에는 약속한 중간 결과와 그 근거, 막힌 원인과 전제 변경을 알린다. 마치면 맡은 작업과 변경 경로, 완료 조건별 검증 결과와 근거, 실패나 미확인 사항, 남은 일을 반환한다.

결과 수락은 조율자가 현재 명세와 실제 산출물을 대조해 결정한다. 보완을 요청받으면 현재 명세를 다시 확인하고, 수정과 검증 결과를 같은 경로로 반환한다.
