# Work

## 완료 조건

요청한 결과마다 완료 조건을 정한다. 조사나 설계만 맡으면 그 결과를 전달하고 마친다. 현재 동작은 근거로 설명하고, 참고 사례는 출처와 참고할 점을 제시한다.

동작 변경은 시작 조건, 사용자 행동, 관찰할 결과로 적는다. 결과를 가르는 조건은 조사로 확인하고, 정책 선택이 남으면 사용자에게 묻는다.

## 작업 선택

완료 조건을 충족하려면 다음에 무엇을 알아내거나 바꿔야 하는지 판단하고 스킬을 고른다.

- 현재 동작은 `$loom:understand`로 조사하고, 참고 사례는 `$loom:explorer`로 찾는다.
- 구현 전에는 `$loom:architect`로 규칙과 책임을 설계한다. 그 결과를 바탕으로 `$loom:implement`에서 기대 동작을 구현하고 검증한다.
- 설계나 구현의 반례는 `$loom:review`로 찾고, 설명이나 문서는 `$loom:write`로 작성하거나 다듬는다.

## 완료 판단

각 완료 조건을 근거와 대조한다. 동작 변경은 시나리오별로 기대 결과와 실제 결과를 비교한다. 차이가 있거나 근거가 부족하면 다음 작업을 선택한다. 모든 조건을 충족하면 결과와 근거를 전달한다.
