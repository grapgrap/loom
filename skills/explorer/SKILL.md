# Explorer

## 무엇을 알아야 판단이 달라지는가

사용자가 지정한 자료나 관심 있는 장면에서 시작한다. 질문이 넓으면 대표 사례 하나를 먼저 살펴보고, 거기서 생긴 구체적인 의문을 따라간다. 비교할 때는 같은 조건과 행동에서 각 사례가 어떤 결과를 내는지 본다.

## 출처가 보여주는 범위를 확인한다

사용 경험은 실제 동작이나 시연에서, 공개된 약속은 공식 문서에서, 내부 판단은 구현에서 확인한다. 발표나 글은 발언의 맥락을 살피고 저자의 주장, 시연한 결과, 우리 쪽 해석을 구분한다. 사용자가 판단의 근거를 다시 찾을 수 있게 해당 구간이나 원문을 연결한다.

사례에서 얻은 방법이 어떤 전제에서 작동하는지 짚는다. 우리 제품에 옮기려면 무엇이 같아야 하는지 설명하고, 현재 동작을 확인할 필요가 있으면 `$loom:understand`의 근거와 대조한다. 외부 제품의 선택은 설계 후보로 다룬다. 채택할 약속은 `$loom:architect`에서 우리 사용자의 장면으로 정한다. 남은 사례가 결론을 바꾸지 않으면 조사 결과와 적용 범위를 전달한다.
