# {사용자가 얻을 결과}

<!-- 여러 세션 또는 독립적인 변경 단위에 걸쳐 작업할 때만 복사한다. 관련 세션에 이 원본의 위치를 전달하고 작업에 필요 없는 절과 이 안내는 삭제한다. -->

## 조율 범위와 담당

{전체 목표 중 이번에 맡은 범위, 조정 책임자와 메인 세션, 사용자 소통과 결과 보고 경로}

## 완료 조건

- {사용자 관점에서 관찰할 결과}
- {유지해야 할 기존 동작}
- {실제 사용 경로의 검증 방법}
- {변경 범위와 맡긴 전달 지점}

## 현재와 변경 후의 그림

{현재 책임·동작과 변경 후의 차이. 확인한 근거와 추정을 구분한다.}

{중요한 선택, 보존할 계약과 각각을 확인할 방법. 구현 중 전제가 바뀌면 영향받는 내용만 갱신한다.}

## 작업 단위

| ID와 완료 결과               | 우선순위와 이유               | 부모와 필요한 선행 결과                 | 담당과 세션                                            | 산출물과 검증 근거                          | 수락과 다음 행동                        |
| ---------------------------- | ----------------------------- | --------------------------------------- | ------------------------------------------------------ | ------------------------------------------- | --------------------------------------- |
| {작업 ID와 관찰 가능한 결과} | {사용자 우선순위와 목표 기여} | {부모 ID, 의존 작업 ID와 필요한 산출물} | {조정 책임자, 수행 세션과 대화, 작업 공간과 통합 담당} | {계약과 산출물 버전, 실행 방법과 관찰 근거} | {수락 여부와 근거, 남은 일과 재개 조건} |

## 공유 계약과 변경

{관련 세션이 지킬 계약과 원본 위치, 맡긴 범위와 권한. 새로 발견한 작업과 직접 대화에서 나온 결정은 영향받는 작업에 반영한다.}

## 아직 결정하지 않은 것

{사람의 선택이 필요한 질문, 실험으로 확인할 질문과 각각의 시점. 없으면 이 절을 삭제한다.}

## 확인된 결과

{완료된 단위의 증거 링크, 실패·미확인과 남은 위험. 작업 중 필요한 만큼만 갱신한다.}
