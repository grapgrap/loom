## 완료 조건

- {사용자 관점에서 관찰할 결과}
- {유지해야 할 기존 동작}
- {실제 사용 경로의 검증 방법}
- {변경 범위와 맡긴 전달 지점}

## 현재와 변경 후의 그림

{현재 책임·동작과 변경 후의 차이. 확인한 근거와 추정을 구분한다.}

{중요한 선택, 보존할 계약과 각각을 확인할 방법. 구현 중 전제가 바뀌면 영향받는 내용만 갱신한다.}

## 작업 단위

현재 정의·관계·진행·검증은 [업무 CLI](../skills/work/references/context-work.md)에 등록한다. 이 문서에는 업무 ID와 추가 설명을 연결하고 CLI의 현재 상태를 별도로 복제하지 않는다.

| 업무 ID | 성립해야 할 결과   | 선행 결과        | 검증 경로            |
| ------- | ------------------ | ---------------- | -------------------- |
| {ID}    | {관찰 가능한 결과} | {없음 또는 결과} | {실행 방법과 산출물} |

## 아직 결정하지 않은 것

{사람의 선택이 필요한 질문, 실험으로 확인할 질문과 각각의 시점. 없으면 이 절을 삭제한다.}

## 확인된 결과

{완료된 단위의 증거 링크, 실패·미확인과 남은 위험. 작업 중 필요한 만큼만 갱신한다.}
