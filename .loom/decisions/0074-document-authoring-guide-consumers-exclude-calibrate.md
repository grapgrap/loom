# 문서 작성 가이드를 모든 작성·검토 경로에서 참조하고 calibrate에서는 제외한다

## 맥락

Loom은 문서 유형별 책임과 언어 중립적인 기술문서 작성 기준을 단일 내부 가이드로 보관한다. 처음에는 shape, review와 calibrate가 이 가이드를 참조하도록 정했다.

그러나 Loom 문서의 작성 경로는 shape에 한정되지 않는다. Plan은 plan 문서를 작성하고 task는 decision을 기록하며 plan을 갱신한다. 이 경로들이 가이드를 참조하지 않으면 같은 문서 유형이 어느 스킬에서 작성되었는지에 따라 서로 다른 기준을 적용받는다.

반면 calibrate는 프로젝트 목표에 대한 concept과 flow의 목적 정렬을 감사하도록 범위가 한정되어 있다. 문서 유형별 책임과 기술문서의 명료성을 누적 감사에 추가하면 목적 정렬과 정합성이라는 서로 다른 준거가 한 스킬에 다시 섞인다.

## 결정

Loom 문서를 작성하거나 검토하는 모든 스킬이 내부 문서 작성 가이드를 참조한다. Calibrate는 가이드를 참조하는 소비자에서 제외하고 목적 정렬 감사에만 집중한다.

- shape는 concept, flow, decision과 index를 작성하거나 갱신할 때 가이드를 적용한다.
- plan은 plan을 작성하고 검증할 때 가이드를 적용한다.
- task는 decision을 기록하거나 plan을 갱신할 때 가이드를 적용한다.
- review와 reviewer는 검토 범위에 포함된 Loom 문서를 평가할 때 가이드를 적용한다.
- calibrate는 가이드를 적용하지 않는다. Concept과 flow의 목적이 프로젝트 목표에 부합하는지를 가늠하는 기존 감사 범위를 유지한다.
- 각 작성 스킬은 최초 Loom 문서를 변경하기 전에 가이드를 읽고, 변경을 마친 뒤 책임 배치와 의미 명료성을 다시 검증한다.
- 가이드 전문은 스킬이나 에이전트에 복제하지 않는다. 각 소비자는 참조 시점과 적용 행동만 정의한다.

### 전제 조건

- Loom 문서를 실제로 작성하거나 검토하는 경로에서 가이드를 적용하면 문서 책임 위반을 예방하거나 세션 안에서 발견할 수 있다.
- 누적 목적 정렬과 세션 산출물의 정합성을 분리하면 calibrate와 review의 준거가 각각 하나로 유지된다.

### 제약 조건

- Calibrate가 가이드를 적용하지 않으므로, 과거 세션에서 누적된 문서 책임 위반을 calibrate가 전수 감사하지 않는다.
  - 제약이 없었다면: 별도의 준거를 섞지 않고도 calibrate가 목적 정렬과 문서 정합성을 함께 감사했을 것이다.

## 대안

### Shape와 review만 가이드를 참조한다

- 설명: 최초에 정한 두 작성·검토 경로에서만 가이드를 적용한다.
- 트레이드오프: plan과 task가 생성하거나 갱신하는 plan과 decision이 가이드 적용 밖에 남는다.

### Calibrate도 가이드를 참조한다

- 설명: calibrate가 누적된 Loom 문서의 책임 배치와 의미 명료성을 함께 감사한다.
- 트레이드오프: 목적 정렬과 문서 정합성이라는 서로 다른 준거가 한 감사에 섞이며, 목적 정렬 전용으로 좁힌 calibrate의 초점이 다시 넓어진다.

### 가이드 전문을 각 스킬에 포함한다

- 설명: 각 작성·검토 스킬이 필요한 기준을 자기 본문에 직접 보관한다.
- 트레이드오프: 같은 계약의 복사본이 여러 곳에 생기고, 변경 시 복사본 사이의 내용이 표류할 수 있다.

## 영향

- shape - Loom 문서 작성 전후에 내부 문서 작성 가이드를 참조한다.
- plan - plan 작성과 검증에 내부 문서 작성 가이드를 참조한다.
- task - decision 기록과 plan 갱신에 내부 문서 작성 가이드를 참조한다.
- review와 reviewer - Loom 문서를 평가할 때 내부 문서 작성 가이드를 참조한다.
- calibrate - 문서 작성 가이드 소비자에서 제외되고 목적 정렬 감사의 기존 범위를 유지한다.
