# aeira 필수 의존을 제거하고 워크트리의 문서를 직접 탐색한다

## 맥락

Loom은 문서 탐색의 토큰 비용과 정확도를 개선하기 위해 aeira를 필수 인프라로 채택하고, 스킬 진입 시 검색·그래프 조회와 문서 변경 후 동기화를 요구해 왔다. 그러나 설치된 aeira는 문서의 절대 경로를 사용자 홈의 레지스트리에 등록하고 별도 DB를 사용한다. 새 워크트리에 문서가 있어도 별도 탐색 준비가 필요하여 여러 에이전트가 각자의 워크트리에서 작업하는 데 부담이 된다.

현재 저장소의 94개 문서를 조사했을 때 decision 84개가 본문 문자량의 약 92%를 차지했다. 인계, 흐름 경계, 리뷰 세션, 문서 탐색의 네 주제에 파일 검색을 적용하면 decision 후보는 각각 4·3·5·8개였다. 경로를 먼저 반환하고 필요한 본문만 읽으면 탐색 단계의 출력을 줄일 수 있었다. 다만 이는 제한된 사례이며 aeira와 검색 품질을 직접 비교한 결과는 아니다. 자연어 표현이 문서 용어와 다르면 검색이 누락될 수 있었다.

사용자는 이 검토를 바탕으로 aeira 필수 의존을 제거하기로 선택했다. 효율적인 탐색 절차는 유지하되 대체 검색 엔진은 지금 도입하지 않는다.

## 결정

Loom의 기본 문서 탐색은 현재 작업 대상 워크트리의 `.loom/` 파일만으로 수행할 수 있어야 한다.

- 스킬의 aeira 검색·그래프 조회 호출과 변경 후 동기화 의무, 설치 안내의 필수 의존을 제거한다.
- index에서 탐색 방향을 파악하고 파일명·제목·본문 키워드로 후보를 좁힌 뒤 관련 본문을 읽는다. 파일 목록과 텍스트 검색에는 실행 환경에서 사용할 수 있는 도구를 사용한다.
- 위키링크를 따라 관계를 확장하고, 역참조는 대상 문서를 가리키는 실제 링크 표기를 검색하여 찾는다.
- shape·plan·task는 decision을 진입 시 일괄 로드하지 않는다. 이전 선택의 근거나 전제 확인이 필요해졌을 때 검색하고, 같은 사안의 결정이 충돌하면 순번이 큰 것을 따른다.
- 검색 결과가 없거나 맥락과 맞지 않으면 동의어·도메인 용어로 재검색한다. 경로와 필요한 구간으로 후보를 선별하여 무관한 본문 로딩을 줄인다.
- 별도 검색 서비스 등록과 인덱스 동기화를 작업의 선행 조건으로 두지 않는다. 검색 누락이나 후보 선별 비용이 반복해서 확인되면 검색 기능 보강을 재검토한다.

### 전제 조건

- 에이전트가 현재 워크트리의 파일을 나열하고 텍스트를 검색할 수 있다.
- index와 문서의 위키링크가 탐색의 진입점과 관계를 제공한다.
- 현재 설계는 concept·flow에서 확인할 수 있고, decision은 선택의 근거가 필요할 때 선별해서 읽을 수 있다.

### 제약 조건

- 키워드 검색은 표현 차이를 자동으로 해소하지 못하며, 큰 문서 집합에서의 탐색 효율은 이번 조사로 검증되지 않았다.
  - 제약이 없었다면: 다양한 규모와 질문으로 검색 품질을 비교하여 의미 검색이나 순위화의 필요성을 판단했을 것이다. 현재는 용어 재검색과 단계적 로딩을 적용하고 실제 누락·비용을 재검토 근거로 삼는다.

## 대안

### aeira를 개선하여 필수 의존으로 유지한다

- 설명: 워크트리별 등록과 DB 준비 부담을 aeira에서 해결한다.
- 트레이드오프: 구조화된 탐색은 유지하지만 Loom의 기본 실행이 외부 도구의 설치와 상태 준비에 계속 의존한다.

### 다른 검색 엔진을 즉시 도입한다

- 설명: aeira 대신 별도 검색 엔진을 기본 탐색 수단으로 제공한다.
- 트레이드오프: 검색 품질 개선 가능성은 있으나 현재 조사에서는 필수 도입의 근거가 부족하며 설치·상태 관리 부담이 다시 생길 수 있다.

## 영향

- shape·plan·task·review·calibrate 스킬 — 파일 검색과 링크 추적으로 탐색하며 aeira 호출을 요구하지 않는다. 각 스킬의 선별 또는 감사 범위는 유지한다.
- 설치 안내 — aeira 설치 요구를 제거한다.
- [[0026-aeira-as-required-infrastructure]] — 효율적인 탐색의 목적은 유지하고 특정 도구가 필수라는 선택을 대체한다.
- [[0068-support-claude-code-and-codex]] — 런타임 공통의 aeira 설치 전제를 제거한다.
- [[0070-remove-plugin-agents]] — 호출 스킬의 직접 탐색과 단계적 로딩은 유지하고 aeira 의존을 제거한다.
